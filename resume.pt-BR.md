## Projetos

### Desafio do Currículo em Nuvem no Azure

**Concluído**

Este site é um currículo em nuvem em evolução, criado para demonstrar desenvolvimento frontend, engenharia de backend em Python, testes automatizados, infraestrutura como código e implantação em nuvem no Azure. O projeto segue padrões de Clean Architecture e código limpo para que cada funcionalidade possa ser desenvolvida, testada e implantada de forma independente.

- Currículo em nuvem semântico, acessível e responsivo
- Hospedagem de site estático no Azure Storage
- Domínio personalizado, HTTPS e CDN pelo Cloudflare
- Contador de visitantes em JavaScript com Azure Functions e Cosmos DB
- Testes automatizados em Python com cobertura obrigatória
- Infraestrutura Azure definida com Bicep
- CI/CD de backend usando GitHub Actions e OIDC
- CI/CD de frontend com invalidação de cache do Cloudflare
